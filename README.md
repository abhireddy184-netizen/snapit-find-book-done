# Get Pros AI

Build a modern, mobile-first home and personal services marketplace called “SnapIt.”

SnapIt helps customers quickly find and book trusted local service professionals.

For the first version, create the frontend design and user experience only. Do not add payments or complicated backend functionality yet.

Brand direction:

- App name: SnapIt

- Tagline: Snap it. Book it. Done.

- Style: modern, premium, trustworthy and easy to use

- Use a clean white background with blue and purple accent colors

- Rounded cards, subtle shadows and clear icons

- Design primarily for mobile, but make it responsive for desktop

- Do not copy the exact appearance of another company

Create these pages:

1. Landing Page

- SnapIt logo and navigation

- Hero headline: “Trusted local services, right when you need them.”

- Subheading explaining that customers can find, compare and book local professionals

- Location input

- Search services input

- “Find a Pro” button

- Popular service categories

- How SnapIt Works section

- Featured professionals

- Customer reviews

- Become a Provider section

- Footer

2. Service Categories Page

Include:

- Plumbing

- Electrical

- HVAC

- House Cleaning

- Handyman

- Lawn Care

- Appliance Repair

- Beauty and Spa

- Moving Help

- Auto Services

Each category should have an icon, short description and “View Providers” button.

3. Provider Search Results Page

- Provider profile picture

- Name and business name

- Verified badge

- Rating and number of reviews

- Starting price

- Distance

- Availability

- Short service description

- “View Profile” and “Book Now” buttons

- Filters for rating, price, distance and availability

4. Provider Profile Page

- Provider information

- Photos of completed work

- Services offered

- Pricing

- Availability calendar

- Reviews

- Service area

- Book Now button

5. Booking Page

Create a simple multi-step booking flow:

- Select service

- Describe the problem

- Upload photos

- Enter service address

- Select date and time

- Review booking request

- Confirm request

6. Customer Dashboard

- Upcoming bookings

- Previous bookings

- Booking status

- Saved providers

- Messages

- Profile and addresses

7. Provider Dashboard

- New job requests

- Upcoming appointments

- Earnings summary placeholder

- Services and pricing

- Availability

- Customer messages

- Reviews

- Profile management

8. Login and Registration Pages

Allow the user to select:

- Continue as Customer

- Continue as Service Provider

Use realistic placeholder content throughout the application. Make all navigation links and buttons functional within the frontend prototype. Create reusable components and maintain consistent branding across every page.
